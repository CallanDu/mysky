为什么选择 MySky

三件小事，让你专注于内容本身。

✦

零依赖

纯 HTML、CSS、JavaScript。不用安装、不用构建，双击就能打开，文件夹始终干净。

☁

轻量清爽

没有多余的库和框架，加载飞快，源码一目了然，新手也能轻松看懂每一行。

❖

响应式

在手机、平板、电脑上都能自动适配布局，自带现代化的视觉风格和柔和动效。

从这里，改成你自己的

打开 index.html 修改文字，打开 css/style.css 调整颜色和样式。把图片放进 assets/ 文件夹，保存后刷新浏览器即可。

每完成一点小改动，就用 Git 保存一个版本：git add . → git commit -m "说明" → git push。
